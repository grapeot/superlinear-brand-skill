# Pitfalls

| Trap | How it shows up | Do this |
|---|---|---|
| The presentation skill's `shoot.py` resets connections | After installing the theme, `tools/shoot.py` reports `net::ERR_CONNECTION_RESET` on a random stylesheet (`brand/canvas.css`, a font) as console errors and failed requests; `render.py deck` passes on the same deck | The stock harness's server keeps the stdlib listen backlog of 5; a themed page requests ~30 files at once. Patch `tools/shoot.py` once, as in [slide_theme.md](slide_theme.md) step 7 (`request_queue_size = 128`), or capture with `render.py deck --all-steps`. Any server you write for a themed deck needs the same backlog |
| Web fonts from a CDN | `fonts.googleapis.com` in a `<link>`; the render works online, fails offline or in CI, and leaks a request | Use `tokens.css` only (vendored WOFF2). `render.py` fails on any external request |
| Fonts declared twice | The scaffold's `deck.css` and `brand/tokens.css` both declare Fraunces, Inter and JetBrains Mono; which file wins depends on load order | Delete the scaffold's five `@font-face` lines ([slide_theme.md](slide_theme.md) step 3) |
| Subset fonts and CJK | Chinese renders in a random system face, or tofu boxes, because the Latin-subset web font has no CJK glyphs and the stack ends in a bare `serif` | Use the token stacks (CJK families listed after the Latin face) and `.sa-zh` on Chinese elements |
| Negative tracking on Chinese | CJK glyphs touch or overlap in a headline | `.sa-zh` resets letter-spacing to slightly positive |
| Emphasis lost in copy slots | The engine fills `data-slot` with `textContent`, so a slotted headline cannot contain `<span class="sa-em">`; or `==markers==` show on the slide | Write `==phrase==` in the copy and load `brand/typeset.js` between `copy.js` and `engine.js`. `render.py` fails on visible `==` |
| Emphasis or units in typewriter text | `==` markers or a split "115 / ms" inside a `.type` element | The engine splits `.type` into letters first; keep emphasis and number+unit pairs out of `.type` |
| Straight quotes, split units | `can't` with a straight apostrophe; "115" at the end of one line and "ms" at the start of the next | `typeset.js` fixes both in slots and static text; `render.py` warns on straight quotes and breakable number+unit spaces, and fails on an actual break |
| SVG labels collide or overflow | A label runs out of its box in a diagram; an axis title touches the last tick ("250requests"); a label is cut at the SVG edge | `render.py` checks SVG text against other text, against the rect it sits in, and against the SVG box. Mark intentional overlaps `data-audit-skip`. Still look: it does not check text against lines, paths or circles |
| Logo through `mask-image` | Logo invisible when the page is opened from `file://` (Chromium blocks the local mask); or the logo got recoloured green | Always `<img>` of the supplied PNG or SVG; never recolour |
| Full historical logo file in a tight header | The logo looks tiny: the historical full SVG includes clear space (about 40% padding) | Historical work: compact SVG in headers. Current work: private six-layer horizontal PNG, with layout-supplied clear space; see `logo_usage.md` |
| Title wraps on the real render | A long title, sized by guess, breaks into three lines or orphans one word; CJK titles wrap at different points than expected | Put `data-max-lines` on titles; check the capacity table in [layouts.md](layouts.md) (cover: ≤ 36 characters at 104 px, `.sa-cover.long` up to ~65 at 80 px); shorten words first; re-render |
| Wide cover cropped | Logo or speaker name cut off on the event page; buttons drawn over the date | Keep everything in the 220/60 px safe area (`sa:safe` meta, audited) |
| Cropped headshot or recording | `object-fit: cover` cuts the chin, a phone screen or the edge of a UI; circle masks cut shoulders | `img.sa-uncropped` / `video.sa-uncropped` (contain) in a hairline frame; get a square original for headshots |
| Light mat around dark media | A black recording or phone screen sits in a pale card with 30 px padding and reads as pasted on | `.sa-frame.tight.dark` for dark footage, `.sa-frame.tight` for light screenshots |
| Identical or missing posters | Screenshots and the PDF show a blank video, or two different recordings look the same because both posters are the same title card | Every `<video>` gets a poster that is a representative frame of that recording; `render.py` fails on a missing poster |
| Green everywhere | Green in the footer, the progress bar, every kicker and two content elements: the audience reads green as decoration and the point disappears | Chrome is neutral (default since this version); content gets one green emphasis per frame; someone else's number stays ink (`.sa-stat .big` without `.accent`) |
| Course-site palette mistaken for the brand | Light green `#79d287`, coral, sticky-note cards appear in a brand piece | That is a course website's palette. Brand = `#238343` + editorial neutrals |
| Retired blue accents | Azure / Maya blue from the April 2026 manual | Superseded by the green. Do not use |
| Green small text too light | `#238343` at 15 px fails contrast (4.2:1) | `--sa-green-text` `#22683b` under 24 px |
| Grey as the second colour | The rejected option reads as disabled, the punchline disappears | Oxblood `--sa-second` with one meaning |
| Shadows and gradients creep back | Cards with drop shadows, gradient backgrounds, glow on the logo | Flat cards with hairlines; hatching for shading. `canvas.css` removes scaffold shadows |
| Class collision with the scaffold | A bordered box appears around a line of text (`.role`), or a line becomes an absolutely positioned italic block with a rule (`.note`) | Avoid the scaffold's global class names inside layouts (list in [slide_theme.md](slide_theme.md)); `render.py` warns (`scaffold_class`) |
| Navigator button in every capture | The round grid button (bottom right) shows on every frame of a screenshot set | `render.py` hides it in captures; `canvas.css` styles it as a hairline control; `<body class="sa-no-navbtn">` hides it for recordings |
| Kicker repeats the running header | The header says "Hosted or your own" and so does the kicker below it | `#part` names the section of the talk; the kicker names what this frame measures or compares |
| Decorative filler | An icon grid or stock illustration fills empty space | Empty space is fine. Add a figure only if it explains something |
| Placeholder shipped | "Speaker Name", "Month DD", the silhouette, or a `.sa-placeholder` in a published image | Run `render.py --final` on the version you ship: it fails on `.sa-placeholder` (boxes and markers), on images from `placeholders/`, and on the stand-in strings. The templates mark their stand-ins with `sa-placeholder`; remove the class with the stand-in |
| Invented facts | A date, price, statistic or quote filled in to make the template look complete | Leave the row or line out until there is a source |
| Sub-brand misuse | "Superlinear AI" mark on a general community promo | Parent brand by default; sub-brand only for AI course / AI community promotions |
| Serving a whole repository | `render.py deck` served a large parent directory to the browser | It serves the deck directory by default; pass `--root` only for a deck that links files above itself |
| Judging from the code | The HTML "looks right" but the PNG has a clipped descender or an overlap | Always open the rendered PNG at full size; the audit catches geometry, not taste |
