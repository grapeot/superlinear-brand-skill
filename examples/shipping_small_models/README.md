# Example deck: "Shipping small models"

A made-up 18-slide talk that shows every layout of the Superlinear Academy brand theme inside a presentation-skill
HTML canvas deck (<https://github.com/grapeot/presentation_skill>). The content is placeholder: the speaker, figures,
recordings and course details are illustrative.

The deck is laid out exactly like the documented install, so its `<head>`, `#chrome` and script block can be copied
into a real deck as they are.

| File | Source |
|---|---|
| `index.html` | Hand-written frames (one per layout) between `FRAMES:BEGIN` / `FRAMES:END`; brand chrome in `#chrome` |
| `brand/` | The skill's `theme/` folder. **In this repository it is a symlink** to `../../skills/superlinear-brand/theme`; in your deck, copy the folder |
| `js/engine.js`, `css/deck.css` | The presentation skill's canvas scaffold (MIT), unmodified except the removed `@font-face` block |
| `js/copy.js` | Speaker notes, plus the slotted copy of the claim slide (`==phrase==` emphasis, filled by the engine and typeset by `brand/typeset.js`) |
| `js/deck.js` | Slide table, and `DECK_HOOKS` that play the recordings on enter and reset them to their posters on leave |
| `media/` | Two synthetic screen recordings (WebM) and their posters, generated by `media/make_media.py` (needs Pillow and an ffmpeg build with `libvpx-vp9`); no real footage |
| `vendor/reveal/` | Reveal.js 5 (MIT, `vendor/reveal/LICENSE`) |
| `screenshots/` | Every slide at its last step and `contact_sheet.jpg`, produced by `render.py deck` |

## View

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory examples/shipping_small_models
# open http://127.0.0.1:8765/
```

Arrow keys or space to step, S for the speaker view, M for the slide navigator.

## Re-render the screenshots

```bash
.venv/bin/python skills/superlinear-brand/scripts/render.py deck examples/shipping_small_models \
  --out examples/shipping_small_models/screenshots
```

The offline-demo slide deliberately contains a `.sa-placeholder`: the render lists it as a warning, and
`--final` fails on it.
